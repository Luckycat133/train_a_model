## 最小复现：实际执行了什么

执行环境：Python 3.13.5，PyTorch 2.10.0+cpu，NumPy 2.3.5，CPU，seed=42。仓库 requirements.txt 要求 torch>=2.13.0；此环境**不满足完整项目依赖**。以下仅复现源码涉及的独立操作，没有导入完整仓库，没有运行 `pytest`、quick、GPU 或 SFT。

| 独立操作 | 实际观察 |
|---|---|
| `torch.save(state, buffer, weights_only=True)` | TypeError：不支持 weights_only 参数 |
| `torch.amp.autocast(enabled=False, dtype=None)` | TypeError：缺少 device_type |
| `torch.amp.GradScaler('cuda', bf16=True)` | TypeError：不支持 bf16 参数 |
| scaler=None 后 scale(loss) | AttributeError |
| `np.array(['床前', '明月光'], dtype=np.int32)` | ValueError |
| `[2,7,3,4]` 原样 SDPA 对比正确转置 | 输出形状相同，最大绝对差约 2.903822 |
| 只改变第一个位置的 V，再看最后位置输出 | 错误布局变化 0；正确布局变化约 2.523705，说明形状检查不足 |
| q=k=0、v=[1,2,9]，比较首个位置输出 | 正确 causal allow-mask 输出 1；反向 bool mask 输出 5.5；直接加 bool 的 naive 输出约 4.800869 |
| 缓存头数 4 与新 KV 头数 2 的 cat | RuntimeError |
| MoE 长度 8 与长度 2 的 load 向量相乘 | RuntimeError |
| checkpoint_sequential(..., attention_mask=None) | ValueError：unexpected keyword arguments |
| 字符词表编码最大匹配词组“床前”“明月光” | 两个 UNK，尽管每个单字均在字符词表 |

这组结果确认错误模式，不构成“11 项仓库测试通过”，也不保证支持版本上的逐字异常信息相同。官方 API 核对来源见 [门禁文档](VALIDATION.md)。目标版本仍须重新跑真实回归。

复现关键数值问题的独立代码（不是仓库 regression suite）：

```python
import torch
import torch.nn.functional as F

torch.manual_seed(42)
torch.set_num_threads(1)
q, k, v = [torch.randn(2, 7, 3, 4) for _ in range(3)]
wrong = F.scaled_dot_product_attention(q, k, v, is_causal=True)
correct = F.scaled_dot_product_attention(
    q.transpose(1, 2), k.transpose(1, 2), v.transpose(1, 2),
    is_causal=True,
).transpose(1, 2)
assert wrong.shape == correct.shape
assert not torch.allclose(wrong, correct, atol=1e-5, rtol=1e-5)
print((wrong - correct).abs().max().item())
```
